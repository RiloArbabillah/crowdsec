## Highlights

- enrich detected security events with request IDs, named routes, content metadata, response status, duration, enforcement action, country/ASN/ISP, HMAC user identity, and parsed browser/OS/device details
- redact configured query secrets plus cookie and authorization match values before persistence or export
- expose the new context through REST API filters, JSON/CSV/Syslog exports, recent-event views, top countries, and device breakdowns
- isolate telemetry failures from WAF enforcement and prevent downstream application requests from being invoked twice

## Upgrade Notes

- run `composer update rilo-arbabillah/laravel-crowdsec`
- run `php artisan migrate` to add the new nullable `security_events` columns
- existing events remain compatible and are not backfilled
- GeoIP enrichment remains opt-in through `CROWDSEC_GEOIP_ENABLED=true`
- only detected security events are enriched; normal requests are not stored as access logs

## Included Changes

- additive security event context migration and indexed filter fields
- Matomo Device Detector integration for browser, OS, and device type parsing
- ASN support and configurable timeout for built-in and custom GeoIP providers
- HMAC-SHA256 authenticated-user correlation with `APP_KEY` fallback
- configurable request ID header and sensitive query parameter list
- enriched dashboard, REST API, and SIEM export contracts
- dedicated privacy, enforcement, migration, API, export, GeoIP, UA, HMAC, and dashboard tests
