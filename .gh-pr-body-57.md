## Summary

- add a dedicated metrics health check and promote insecure API/dashboard checks to failures in `crowdsec:doctor`
- make the doctor command exit non-zero whenever any health check fails
- add doctor and metrics coverage for secure defaults and insecure endpoint configurations
- document production-safe endpoint configuration examples in `README.md`
